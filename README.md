# Avidus Interactive Assignment

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Features

### User
- Register/Login
- Create Tasks
- View Own Tasks
- Delete Tasks

### Admin
- View All Users
- View All Tasks
- Activity Logs
- Update User Status

### Activity Logs
- Login Activity
- Task Create
- Task Update
- Task Delete

## Run Backend

cd backend
npm install
npm run dev

## Run Frontend

cd frontend
npm install
npm run dev
